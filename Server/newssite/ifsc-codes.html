IFSC Code Finder

IFSC (Indian Financial System Code) is an 11-character alphanumeric code assigned by the Reserve Bank of India to every bank branch in India. This code is essential for electronic fund transfers via NEFT, RTGS, and IMPS.

How IFSC Code Works

The first 4 characters represent the bank code, the 5th character is always 0 (reserved for future use), and the last 6 characters identify the specific branch. For example, in SBIN0001234: SBIN = State Bank of India, 0 = reserved, 001234 = branch code.

Why You Need IFSC Code

IFSC codes are mandatory for all electronic fund transfers in India including:

  • NEFT (National Electronic Funds Transfer) - For non-urgent transfers
  • RTGS (Real Time Gross Settlement) - For high-value instant transfers
  • IMPS (Immediate Payment Service) - For instant mobile payments
  • UPI - Unified Payments Interface transactions
  • Online banking and bill payments
  • Mutual fund investments and insurance premiums

What is IFSC Code?

IFSC stands for Indian Financial System Code. It is an 11-character alphanumeric code that uniquely identifies every bank branch participating in the two main Electronic Fund Settlement Systems in India - the Real Time Gross Settlement (RTGS) and the National Electronic Funds Transfer (NEFT) systems.

The IFSC code is assigned by the Reserve Bank of India (RBI) and can be found on your cheque book, bank passbook, or on the RBI website. It is essential for facilitating electronic payments and settlements.

Structure of IFSC Code

  • First 4 characters - Represent the bank (e.g., SBIN for State Bank of India, HDFC for HDFC Bank)
  • 5th character - Always 0 (zero), reserved for future use by RBI
  • Last 6 characters - Represent the specific branch (alphanumeric)

❓ Frequently Asked Questions

What is IFSC Code and where can I find it?▼
IFSC (Indian Financial System Code) is an 11-character code that identifies bank branches in India. You can find it on your cheque book (printed at the top), bank passbook, bank's website, or through our IFSC Code Finder tool above.
Is IFSC Code same for all branches of a bank?▼
No. Each branch of a bank has a unique IFSC code. While the first 4 characters identify the bank, the last 6 characters are unique to each branch. So two branches of the same bank will have different IFSC codes.
What happens if I use wrong IFSC Code?▼
If you use an incorrect IFSC code, the transaction may fail and the amount will be returned to your account within a few working days. In some cases, it may get credited to a wrong branch. Always verify the IFSC code before initiating any transaction.
Can IFSC Code change for a branch?▼
Yes, IFSC codes can change when banks merge or branches are relocated. For example, after the merger of several public sector banks in 2020, many branch IFSC codes were updated. Always verify the latest IFSC code before making transactions.
What is the difference between IFSC and MICR code?▼
IFSC (11 characters) is used for electronic fund transfers (NEFT, RTGS, IMPS). MICR (9 digits) is a code printed on cheques using magnetic ink for cheque-based transactions. Both identify bank branches but serve different purposes.
Is IFSC Code required for UPI transactions?▼
Generally, UPI transactions use VPA (Virtual Payment Address) so you don't need to manually enter IFSC code. However, the IFSC code is used internally by the system to route your transaction to the correct bank branch.
