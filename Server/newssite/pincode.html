PIN Code Finder

PIN Code (Postal Index Number) is a 6-digit code used by India Post to identify specific post offices across India. It was introduced on 15 August 1972 to simplify the sorting and delivery of mail.

How PIN Code Works

The first digit indicates the region, the second digit the sub-region, the third the sorting district, and the last three digits identify the specific post office. For example, in 110001: 1 = Northern Region, 11 = Delhi, 0 = Delhi sorting district, 001 = Connaught Place post office.

What is a PIN Code?

PIN Code stands for Postal Index Number. It is a 6-digit numerical code assigned by India Post (Department of Posts, Government of India) to every post office in the country. The PIN code system was introduced on 15 August 1972 by Shriram Bhikaji Velankar, an additional secretary in the Union Ministry of Communications.

India has over 1,55,000 post offices — the largest postal network in the world. Each post office has a unique PIN code that helps in efficient sorting and delivery of mail and parcels.

  • Zone 4 — Maharashtra, Goa, Madhya Pradesh, Chhattisgarh
  • Zone 5 — Andhra Pradesh, Telangana, Karnataka

  • Zone 7 — West Bengal, Odisha, Assam, Sikkim, NE States, Andaman & Nicobar
  • Zone 8 — Bihar, Jharkhand
  • Zone 9 — Army Postal Service (APS)

❓ Frequently Asked Questions

What is a PIN Code and why is it important? ▼
PIN Code (Postal Index Number) is a 6-digit code used by India Post to identify specific post offices. It is essential for accurate mail delivery, online shopping deliveries, and address verification. Without the correct PIN code, your mail or package may be delayed or misdelivered.
How many post offices are there in India? ▼
India has over 1,55,000 post offices, making it the largest postal network in the world. About 90% of these are in rural areas. India Post employs over 4 lakh people and handles over 15 billion mail pieces annually.
Can two post offices have the same PIN code? ▼
Yes, multiple post offices (sub-offices and branch offices) can share the same PIN code as the head post office in their area. The PIN code identifies the delivery area, not necessarily a single post office building.
What is the difference between HPO, SO, and BO? ▼
A Head Post Office (HPO) is the main post office in a district. A Sub Post Office (SO) operates under an HPO and serves a specific area. A Branch Post Office (BO) is the smallest unit, usually in rural areas, operating under an SO. Branch offices may share the PIN code of their parent sub-office.
How do I find the PIN code for my area? ▼
You can find your area's PIN code using our PIN Code Finder above — either enter a 6-digit PIN code to get post office details, or search by your area/locality name. You can also find PIN codes on your utility bills, bank statements, or by asking at your nearest post office.
Is PIN code the same as ZIP code? ▼
PIN code is India's equivalent of the ZIP code used in the United States. Both serve the same purpose — identifying geographic areas for mail delivery. However, Indian PIN codes are always 6 digits, while US ZIP codes are 5 digits (sometimes extended to 9 with a hyphen).
